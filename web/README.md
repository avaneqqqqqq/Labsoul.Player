# labsoul — веб-интерфейс

Клиент плеера: ванильные ES-модули, без сборщика, фреймворков и внешних CDN.
Сервер отдаёт эту папку как статику и JSON по контракту `../CONTRACT.md`.

## Как посмотреть

```bash
# полноценно: API, поиск, волна, потоки (из корня player/)
node server/index.mjs            # → http://127.0.0.1:5270

# только интерфейс, без API (демо-режим, чистый консоль)
node web/preview.mjs             # → http://127.0.0.1:5390
```

Если API не отвечает (или это превью), интерфейс сам переходит в демо-режим:
лента, поиск и история наполняются локальным набором из `js/demo.js`, в шапке
появляется предупреждение, плеер симулирует воспроизведение. Как только сервер
поднялся, «Проверить снова» переводит приложение на настоящие данные.

## Экраны

- **Волна** — лента `/api/wave`, лайк/дизлайк/скип → `/api/wave/feedback`,
  «в очередь», автодогрузка при скролле, менеджер блоков.
- **Поиск** — `/api/search` с фильтрами источников и группировкой; бейджи
  «30 сек» / «Plus» / «недоступно» по `playable` и `reason`.
- **Библиотека** — `/api/history` по дням + локальное избранное
  (`localStorage: player-likes`).
- **Подключения** — `/api/status` и `PUT /api/settings`: OAuth-токен Яндекса,
  client id/secret Spotify, необязательный client_id SoundCloud + инструкции.
- **Оформление** — пресеты, схемы dark/light/amoled, стили glass/vinyl/neon/paper,
  акцент из обложки (canvas-квантование), обои, плотность, радиусы, размытие,
  шрифт, зерно, анимации, блоки, экспорт/импорт темы в JSON и 10-полосный
  эквалайзер (Web Audio: `createMediaElementSource → preamp → 10 × BiquadFilter
  → GainNode`).
- **Плеер** — нижняя панель: обложка, seek, play/pause, prev/next, shuffle,
  repeat (off/all/one), громкость, очередь с drag-and-drop.

## Память

| Ключ | Что хранится |
|---|---|
| `player-theme` | вся тема: токены, обои, блоки, эквалайзер |
| `player-likes` | избранные треки (объекты Track) |
| `player-ui` | громкость, mute, shuffle, repeat |
| `player-library-tab` | активная вкладка библиотеки (sessionStorage) |

`player-theme` — контрактный ключ, не переименовывать (миграции не нужны).

## Клавиши

`Space` — play/pause · `←/→` — ±5 сек · `↑/↓` — громкость · `M` — mute ·
`L` — лайк · `N/P` — следующий/предыдущий · `S` — shuffle · `R` — repeat ·
`Ctrl+K` или `/` — поиск · `Esc` — закрыть очередь/тост.

## Структура

```
index.html          каркас оболочки и SVG-символы
css/base.css        токены, схемы, варианты, фон, зерно
css/app.css         оболочка, плеер, очередь, компоненты
css/screens.css     экраны + адаптив (1280 / 980 / 820 / 700 / 460)
js/main.js          точка входа, hash-роутинг, жизненный цикл экранов
js/api.js           клиент CONTRACT.md + переход в демо-режим
js/audio.js         <audio>, очередь, Web Audio-эквалайзер, история
js/theme.js         тема: применение, пресеты, импорт/экспорт
js/covers.js        canvas-квантование обложек
js/store.js         лента, поиск, история, статусы, лайки
js/ui.js            шапка, сайдбар, плеер, очередь, модалки, клавиши
js/components.js    иконки, строки, карточки, бейджи
js/screens/*.js     Волна, Поиск, Библиотека, Подключения, Оформление
js/demo.js          демо-треки для просмотра без сервера
```

Тесты: `node --check` на всех `.js`; интерфейс проверялся в headless Chromium
на 1920/980/760/390 px, включая реальный поток и применение EQ-полос.
