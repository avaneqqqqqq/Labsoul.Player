## ГЛАВНОЕ НА ЗАВТРА

**Одна нерешённая проблема: поток SoundCloud у провайдера.**

Что уже известно точно:

```
метаданные, поиск, волна   →  работают  ✓
плейлист HLS (26 КБ)       →  200 за 205 мс  ✓
аудио-сегмент (200+ КБ)    →  ТАЙМАУТ  ✗
   и напрямую, и через релей
```

**Причина:** провайдер рвёт большие ответы — не по домену, а по размеру.
`playback.media-streaming.soundcloud.cloud` открывается, `/media/` открывается,
а сам сегмент — нет. Поэтому zapret тут **не помогает** (он режет по домену).

**Что найдено:**
- кусками по 8 КБ через Range — **работает**, но медленно: 3.82 МБ за 191 с
  (~478 запросов, 2.5 с на кусок)
- целым сегментом — таймаут

**Что делать завтра — первым делом:**
Прогнать тест размера куска: 8, 16, 32, 64, 128 КБ через Range-запрос.
Найти максимальный, который проходит. Поставить его в `CHUNK_BYTES`
(сейчас 8 КБ в `server/providers/soundcloud.mjs`). Расчёт: при 64 КБ это
будет ~60 запросов вместо 478 — около 20 секунд вместо 191.

Затем проверить, проходит ли сегмент через релей кусками — возможно,
через релей можно качать целиком.

## Что работает в 2.0.0

### Релеи SoundCloud — работают

Два своих сервера-посредника на бесплатном хостинге:

```
https://labsoul.netlify.app                                   (100 ГБ/мес)
https://labsoul-relay.danil-chichov-za.workers.dev           (100k запросов/день)
```

Проверено: `soundcloud.com` 200, CDN обложек 200, чужой домен 403 (защита).
Код в репозитории: `relay/`. Секретов нет (проверено).

Логика в `server/providers/screlay.mjs`: сначала напрямую, при ошибке — через
релей; рабочий запоминается. Токены Cloudflare и Netlify — у пользователя,
в код не писать.

### Тумблер обхода — выключен по умолчанию

В Подключениях: `Обход блокировки (zapret)`. Состояние
`network.bypass.enabled` в настройках. Пока выключен — плеер **не трогает**
чужие списки zapret и не поднимает `winws`.

### Тексты — 100% на 20 треках

```
60% треков  → 60–100 мс
среднее     → 765 мс
20/20 найдено
```

Источники: lrcmux (караоке по слову), lrclib, NetEase, KuGou напрямую, Genius.
Что исправлено: гонка источников (отдаём первый с таймингами, не ждём всех),
до трёх повторов, поиск по названию без исполнителя, адаптивный ограничитель
частоты для lrclib.

**Пользователь говорит, что текста всё равно нет** — не сошлось. Завтра
проверить: возможно, дело в кэше на клиенте (`lyricsMemo`) или в том, что
`isDemo()` включается раньше ответа сервера.

### Токен SoundCloud обновляется сам

Найден `oauth_refresh_token` в cookie (32 символа). Токен живёт сутки.
Модуль `server/providers/sctoken.mjs`:

```
POST secure.soundcloud.com/oauth/token
grant_type=refresh_token
refresh_token=<из cookie>
client_id=<из самого JWT, поле client_id>
→ 200, новая пара токенов
```

⚠️ **refresh_token одноразовый.** При обмене старый аннулируется. Если
потратить его тестом и не сохранить новый — нужен повторный вход.

### Яндекс — работает

```
статус    229 мс  (ryzleitsevdan)
поиск     163–278 мс
поток     44 мс
волна     14 треков за 1845 мс
избранное 100 треков
```

`server/net.mjs` — пул хостов: каждый запрос перебирает
`api.music.yandex.net` → `.ru` → `music.yandex.ru/api`.

### Кнопка плей/пауза — одна на все 6 мест

`web/js/control.js`:

```
522:  название в баре
527:  кнопка в баре
1636: полноэкранный
1675: пробел (полный экран)
2164: пробел (основное)
2246: мини-плеер
```

Все зовут `control.toggle(origin)` — она переключает и обновляет **обе**
панели (бар и полноэкранный) сразу и через кадр.

## ЛОВУШКИ

1. **`build.files` — явный список.** Новый `.cjs` без записи в `app/package.json`
   не попадёт в установщик.
2. **Папка-двойник** — см. пути.
3. **Кодировка:** не править русский текст через PowerShell. Только `edit`/`write`.
4. **`isDemo()`** — демо только при `net.mode === 'demo'`.
5. **Стили клипа и текста** — `nowplaying.css`, не `app.css`.
6. **Каждая настройка** должна нормализоваться в `normalizeTheme`.
7. **Запуск приложения из моего окружения заблокирован** — проверять статически
   и на сервере, а интерфейс — по скриншотам пользователя.
8. **refresh_token одноразовый** — после обмена сохранять новый.
