# Подпись кода и автообновление labsoul

Документ отвечает на два вопроса: **как подписать установщик** и **как работает автообновление**,
и честно говорит, что из этого можно сделать без денег.

---

## 1. Зачем подпись

Windows показывает предупреждение SmartScreen для установщиков **без подписи** и для подписанных
**самоподписанным** сертификатом: «Windows защитила ваш компьютер». Пользователь должен нажать
«Подробнее → Выполнить в любом случае».

Подпись сертификатом от удостоверяющего центра (CA) снимает это предупреждение — при условии, что
сертификат «набрал репутацию» (для OV это обычно несколько недель/скачиваний, для EV — сразу).

| Вариант | SmartScreen | Стоимость | Годится для распространения |
|---|---|---|---|
| Без подписи | предупреждение | 0 | формально да, но людей пугает |
| Самоподписанный | предупреждение (кроме машин, где сертификат в доверенных) | 0 | для тестов и своих машин |
| OV-сертификат | предупреждение, пока нет репутации | ~150–300 $/год | да |
| EV-сертификат | предупреждения нет сразу | ~300–500 $/год | да |

Сертификат покупается у DigiCert, Sectigo, GlobalSign и подобных; выдают после проверки
организации/ИП. Это единственный шаг, который нельзя сделать кодом.

## 2. Как подписать (когда сертификат есть)

Подпись ставится **отдельным шагом** (`tools/sign-release.ps1`), потому что встроенная подпись
`electron-builder` требует пакета `winCodeSign` с macOS-симлинками, которые Windows без прав
разработчика не создаёт.

Скрипт делает три вещи по порядку, и это важно: подпись меняет байты файла, поэтому после неё
он **пересобирает `blockmap`** и **пересчитывает `sha512` в `latest.yml`**. Благодаря blockmap
автообновление дифференциальное — клиент докачивает только изменившиеся блоки, а не все 78 МБ.

```powershell
cd app
$env:CSC_LINK = "C:\путь\cert.pfx"      # или base64-строка PFX
$env:CSC_KEY_PASSWORD = "пароль"
npm.cmd run dist
```

Конфигурация сборки уже готова: `signAndEditExecutable: true` в `app/package.json`.

Проверить результат:

```powershell
Get-AuthenticodeSignature .\dist\labsoul-*-setup.exe | Format-List Status, SignerCertificate
```

Если сертификат установлен в хранилище и подписывать нужно готовый файл (например, пересобрать
`latest.yml` не требуется):

```powershell
powershell -ExecutionPolicy Bypass -File tools\sign-installer.ps1 -Thumbprint <отпечаток>
```

## 3. Самоподписанный сертификат — для локальных проверок

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-test-cert.ps1 -Password labsoul
# при желании доверить локально:
powershell -ExecutionPolicy Bypass -File tools\make-test-cert.ps1 -Password labsoul -Trust
```

Создаёт `cert-test.pfx` (в `.gitignore`) и сертификат в `Cert:\CurrentUser\My`.
С `-Trust` добавляет его в доверенные корни **текущего пользователя** — тогда на этой машине
подпись считается доверенной. На других машинах — нет.

Удалить потом:
```powershell
Remove-Item Cert:\CurrentUser\My\<отпечаток>
Remove-Item .\cert-test.pfx
```

## 4. Автообновление

Поток в приложении:

1. При старте (и по меню **labsoul → «Проверить обновления…»**) сервер опрашивает публичные релизы
   GitHub, отбирая только релизы с ассетом `labsoul-*-setup.exe` (старые релизы прежнего мода
   игнорируются).
2. Если версия новее — всплывает плашка **«Доступна версия X»** с кнопкой «Скачать».
3. «Скачать» → `electron-updater` качает установщик, плашка показывает прогресс.
4. По готовности кнопка меняется на **«Перезапустить»** → `quitAndInstall()` ставит обновление.
5. «Позже» запоминает версию: с этим обновлением больше не всплывает.

Условия, без которых автообновление не сработает:

- релиз **опубликован** (не черновик) — иначе `electron-updater` его не видит;
- в релизе есть `latest.yml` (сборка кладёт его в `app/dist`);
- версия в `package.json` выше опубликованной (сейчас база — **1.0.0**; релизы прежнего мода
  `0.2.x` специально ниже, чтобы не перетягивать обновление).

Если скачивание невозможно, плашка показывает ошибку, а кнопка ведёт на страницу релиза —
обновление всегда можно поставить вручную.

## 5. Проверка подписи и обновления перед публикацией

```powershell
npm.cmd test                       # 50 проверок: ядро, вход, поток, мок Яндекса
Get-AuthenticodeSignature .\app\dist\labsoul-*-setup.exe
Start-Process ".\app\dist\labsoul-*-setup.exe"     # установить и запустить
```

## 6. Что где лежит

| Файл | Назначение |
|---|---|
| `tools/make-test-cert.ps1` | самоподписанный сертификат для локальных тестов |
| `tools/sign-installer.ps1` | подпись готового установщика (PowerShell, без Windows SDK) |
| `.github/workflows/release.yml` | CI-сборка по тегу `v*` с прикреплением файлов к релизу |
| `app/dist/latest.yml` | манифест автообновления (версия, sha512, размер) |
| `app/dist/*.blockmap` | карта блоков для дифференциального обновления |
