# Токены и ключи labsoul

labsoul — локальное приложение: **все ключи хранятся только на вашем компьютере**, в файле
`data/settings.json` (папка `data/` в `.gitignore` и никогда не попадает в репозиторий).
В интерфейсе секреты показываются замаскированными (`••••1234`).

Вводить ничего не обязательно: плеер запустится и без токенов, просто источники будут пустыми.

---

## 1. Яндекс.Музыка — OAuth-токен

Нужен для поиска, воспроизведения и настоящей «Моей волны».

> **В десктопном приложении токен искать не нужно:** «Подключения» → **«Войти в Яндекс.Музыку»**.
> Откроется сам Яндекс.Музыка в отдельном окне: входите как обычно — labsoul перехватит токен из
> запросов сервиса, сохранит его и закроет окно. Если автоматический вход не сработает, предложит
> запасной вариант (OAuth-окно или ручная вставка). Инструкция ниже — для браузерной версии.

1. Откройте <https://music.yandex.ru> и войдите в свой аккаунт.
2. Нажмите `F12` → вкладка **Network** → в фильтре наберите `api.music.yandex.net`.
3. Обновите страницу (`F5`) и кликните на любой запрос к `api.music.yandex.net`.
4. В блоке **Headers → Request Headers** найдите строку:

   ```
   authorization: OAuth y0_AgAAAAB...
   ```

5. Скопируйте **всё после слова `OAuth`** — это и есть токен (обычно начинается с `y0_`).

Вставьте его в labsoul: **Подключения → Яндекс.Музыка → Токен → Сохранить**.

> Токен действует долго, но его можно отозвать в настройках Яндекс ID. Если Яндекс начал
> отвечать `401` — просто получите новый тем же способом.

Качество звука переключается там же: `nq` (192 kbps), `lq` (128 kbps), `lossless` (если есть подписка).
Для `lossless` плеер скачивает зашифрованный FLAC и расшифровывает его на лету.

## 2. SoundCloud — ничего не нужно

`client_id` плеер добывает сам: открывает <https://soundcloud.com>, находит его в JS-бандлах
и кэширует. При истечении — обновляет автоматически.

Если SoundCloud не работает (например, из-за блокировки), `client_id` можно вставить вручную:

1. Откройте <https://soundcloud.com>, `F12` → **Network**.
2. Найдите любой запрос к `api-v2.soundcloud.com`.
3. Скопируйте из URL параметр `client_id=...` (32 символа).

Ограничения сервиса: часть треков доступна только подписчикам Go+ — они помечаются в плеере
как недоступные и не попадают в очередь.

## 3. Spotify — Client ID и Client Secret

Нужны только для поиска и импорта каталога. Полноценное воспроизведение Spotify сторонним
плеерам недоступно (официальный Web API отдаёт максимум 30-секундные превью, а с ноября 2024
года новым приложениям они не выдаются вовсе) — треки Spotify показываются и матчатся на
Яндекс/SoundCloud, играть их нужно в приложении Spotify.

1. Откройте <https://developer.spotify.com/dashboard> и войдите.
2. **Create app**: название `labsoul`, Redirect URI — `http://127.0.0.1:5270/callback`, отметьте **Web API**.
3. В созданном приложении: **Settings** → скопируйте **Client ID**, затем **View client secret** → **Client Secret**.
4. Вставьте оба значения в labsoul: **Подключения → Spotify → Сохранить**.

## 4. GitHub — токен для публикации (только для разработки)

Нужен лишь для того, чтобы заливать сборку в репозиторий (`tools/push-github.mjs`), в самом
плеере не используется.

1. Откройте <https://github.com/settings/personal-access-tokens/new> (fine-grained token).
2. **Token name**: `labsoul-push`, **Expiration**: 7 days.
3. **Repository access** → *Only select repositories* → `Ymuz.mod`.
4. **Permissions → Repository permissions → Contents**: *Read and write* (Metadata подтянется сам).
5. **Generate token** и скопируйте `github_pat_...`.

Положите токен в файл `data/.github-token` (одна строка, без кавычек) или задайте переменную
`GH_TOKEN`. Затем:

```powershell
node tools/push-github.mjs            # dry-run: покажет, что изменится
node tools/push-github.mjs --apply    # закоммитит содержимое папки в ветку main
```

Токен одноразовый по смыслу задачи — после публикации его можно отозвать.

## Можно ли обойтись без токенов?

Короткий ответ: **полностью — нет, но почти всё работает и без ручного копирования ключей.**

| Сервис | Без токена |
|---|---|
| **SoundCloud** | Работает целиком: `client_id` плеер добывает сам при запуске. |
| **Яндекс.Музыка** | Не работает: API не отдаёт ни поиск, ни «Мою волну», ни поток без OAuth. Токен придётся получить один раз (30 секунд, см. выше) — хранится локально и действует долго. |
| **Spotify** | Поиск по каталогу не работает без ключей, но **ссылка на трек — работает**: вставьте её в «Поиске» (поле «или вставьте ссылку»), labsoul разберёт метаданные через публичный oEmbed и найдёт играбельную версию в Яндексе/SoundCloud. |

Важно: **«Волна» работает и без Яндекса.** В шапке волны выбери источники — если Яндекс не
подключён, лента соберётся из SoundCloud (локальные рекомендации по истории и лайкам), а Spotify
можно добавить как каталог для матчинга.

## Правила безопасности

- Никогда не коммитьте `data/` — там токены и история прослушивания.
- Не публикуйте токены в скриншотах и логах: `data/server.log` тоже локальный.
- Приложение не отправляет ваши данные никуда, кроме самих музыкальных сервисов.
